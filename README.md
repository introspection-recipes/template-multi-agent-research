# Multi-Agent Research Template

A starter template inspired by Anthropic's multi-agent research system.

## Quick Start

Click **Use this template** above to create your repository, then run:

```bash
pi install npm:@introspection-ai/recipes
cd your-repository
PARALLEL_API_KEY=your-key pi --recipe .
```

## What's Included

- A lead researcher that plans, delegates, and synthesizes
- Parallel research subagents
- A final citation pass

[Read the Recipes documentation →](https://pi.recipes/docs)
